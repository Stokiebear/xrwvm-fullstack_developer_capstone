# Dealership Reviews Web Application

Repository Name: xrwvm-fullstack_developer_capstone  
Project Name: Dealership Reviews Application

## Project Description
This project is a full-stack web application built using Django and Node.js that allows users to view car dealerships and submit reviews. The application is containerized using Docker and deployed on a Kubernetes cluster.

Users can:
- Register and log in
- View a list of dealerships
- View dealer details and reviews
- Add reviews for dealerships
- Access an admin panel

## Technologies Used
- Django
- Node.js
- SQLite
- Docker
- Kubernetes
- HTML / CSS / Bootstrap
